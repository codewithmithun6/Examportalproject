Start Anugular implementation from begning
=============================================
1. download nodejs and install (https://nodejs.org/en) 
2. open cmd and check version 
   2.1) node -v
   2.2)	npm -v
3. open angular cli (https://angular.io/cli) and follow the steps
4. npm install -g @angular/cli
5. ng --help
6. ng new --help
7. open cmd in your project location where you want to create project(eg: D:\SpringBoot project2023\Examportalproject>)
8. D:\SpringBoot project2023\Examportalproject> ng new examfront
   Would you like to add Angular routing? Yes
   Which stylesheet format would you like to use? CSS
9. cd examfront
10. ng serve    ----->run the server	


11. https://material.angular.io/guide/getting-started  (follow the steps)
12. D:\SpringBoot project2023\Examportalproject> ng add @angular/material

13. https://github.com/dmhendricks/bootstrap-grid-css    (follow the steps if we have required grid then we can use of this link)

14. npm install bootstrap-grid-only-css --save
//15. bower install bootstrap4-grid-only 

16. open angular.json and update in styles ("./node_modules/bootstrap-grid-only-css/dist/css/bootstrap-grid-min.css")

 "styles": [
              "@angular/material/prebuilt-themes/indigo-pink.css",
              "src/styles.css",
              "./node_modules/bootstrap-grid-only-css/dist/css/bootstrap-grid.min.css"
            ],



Now create two folder inside app (components and pages)

D:\SpringBoot project2023\Examportalproject\examfront\src\app> mkdir components
D:\SpringBoot project2023\Examportalproject\examfront\src\app> mkdir pages

Create navbar and footer component inside components folder (ng generate component navbar) below is written shortcut

D:\SpringBoot project2023\Examportalproject\examfront\src\app\components> ng g c navbar 
D:\SpringBoot project2023\Examportalproject\examfront\src\app\components> ng g c footer

create signup and login component inside pages componets

PS D:\SpringBoot project2023\Examportalproject\examfront\src\app\pages> ng g c signup
PS D:\SpringBoot project2023\Examportalproject\examfront\src\app\pages> ng g c login
